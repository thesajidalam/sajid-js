Small, reliable JS helpers. Zero dependencies.

sajid-js is a lean JavaScript utility library for building faster without the bloat. Grab a handful of battle-tested helpers for arrays, strings, numbers, objects, dates and async — or run them all live below.

⚡ Zero dependenciesJust plain JavaScript. One file, no build step, no node_modules to babysit.
🌍 Browser + NodeUMD build works everywhere — a <script> tag or a require().
🧩 65+ utilitiesshuffle, slugify, clamp, debounce, memoize, timeAgo and more, each tree-shakeable.
✅ TestedCovered by a passing test suite (npm test) for reliability.
🚀 Getting started for JS developers
  • <script src="src/sajid.js"></script> → window.sajid
  • npm install sajid-js → const sajid = require('sajid-js')
  • Example: sajid.slugify('Hello, World!') → "hello-world"
Install
<script src="src/sajid.js"></script>
// → window.sajid
npm install sajid-js
